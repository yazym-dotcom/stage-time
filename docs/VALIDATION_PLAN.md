# Proposed usability pilot

This is a future research plan. No participant results are being claimed.

## Question

Can someone new to Stage Time start a useful practice session, interpret the feedback, and identify one change to try next?

## Suggested scope

Invite 3–5 people preparing for an interview, presentation, or stakeholder discussion. Use the browser demo for early navigation and comprehension checks. Test actual speech analysis separately on the local app; the static demo cannot establish that capability.

## Tasks

1. Find a lesson suited to an upcoming speaking situation.
2. Explain the technique in their own words.
3. Move through the practice flow.
4. Explain which feedback is useful and what they would change next.
5. Find a framework or roleplay they would want to use again.

## Record

- Whether each task was completed without help.
- Where the person paused, misinterpreted a label, or needed guidance.
- Whether they correctly recognized sample versus real feedback.
- Whether they could identify an actionable next step.
- Reasons they would or would not return; follow up on actual use where possible.

Ask permission before recording a session. An anonymized observation log is sufficient for the initial study.

## Decision rules

Repeated navigation confusion should lead to a flow or labeling change. Confusion about scores should lead to clearer explanations before new metrics are added. Requests for more features should be tied to observed tasks rather than treated as validation by themselves.

Do not use this small pilot to claim market size, statistically established learning benefits, or validated AI accuracy. It is an early product-learning exercise.
